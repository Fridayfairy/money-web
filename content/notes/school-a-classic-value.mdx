## 这派在回答什么问题

「这是不是一门我愿意长期持有的好生意，并且现在价格给了足够折扣？」不问题材高度，不问连板，很少追宏观 beta。

## 代表人物

巴菲特、格雷厄姆、费雪、芒格、邓普顿、卡拉曼（插件 id：`buffett` / `graham` / `fisher` / `munger` / `templeton` / `klarman`）。

## 核心评判维度

| 人物 | 关键规则（插件摘要） |
| --- | --- |
| 巴菲特 | ROE 连续多年 >15%、净利率、负债、FCF、质押；公式近似「硬性达标×60 + 护城河×25 + 估值×15」 |
| 格雷厄姆 | 七项硬筛：PE&lt;15、PB&lt;1.5、PE×PB&lt;22.5、流动比&gt;2、长盈利/分红/盈利增长等，达标数/7×100 |
| 费雪 | 15 要点：产品、研发、销售、利润率、管理层深度与诚信等 |
| 芒格 | 从 100 起逆向扣分：失败路径、偏误、护城河、管理层、简单数学 |
| 邓普顿 | 最大悲观时买：PE 历史低位、全球相对便宜、危机后的行业 |
| 卡拉曼 | 强调安全边际（常要 30%+）、催化剂、下行保护 |

字段多落在财报、估值、治理、护城河维度。

## 什么会被否决 / skip

- 商业模式说不清、能力圈外（典型：单纯商品价格接受者、金矿等）。
- 格雷厄姆式：估值与资产负债表同时炸穿。
- 卡拉曼：现价相对内在价值是**负**安全边际时，现金也是仓位。
- 费雪：没有可持续的产品/工艺迭代故事，只有牌照与 tonnage。

## 和研报怎么对照

看 A 组卡片的 `headline` 是否引用 ROE 历史、PE/PB、DCF/安全边际；若规则引擎因某一两年 ROE 好看给高分，但 DuPont 还原很差或能力圈外，agent 应覆盖为看空。

## 一句话边界

价值派买的是「可理解的复利 + 折扣」，不是「金价/题材涨了利润好看」。周期高峰上的漂亮 ROE，经常是陷阱而不是通行证。
