## 这派在回答什么问题

「生意懂不懂、人靠不靠谱、价格贵不贵？有没有预期差或产能周期上的赔率？」偏基本面，但比经典价值更贴 A 股治理与产业节奏。

## 代表人物

段永平、张磊、张坤、林园、冯柳、邓晓峰、邱国鹭（插件里对应 `duan` / `zhang_lei` / `zhangkun` 等）。

## 核心评判维度

| 人物 | 关键框架（插件摘要） |
| --- | --- |
| 段永平 | 三问：懂不懂、好不好、贵不贵；不懂 → 不碰 |
| 张磊 | 长期主义、护城河、组织能力 |
| 张坤 | GARP：成长质量与估值匹配，重 ROE 与持有体验 |
| 林园 | 高确定性、垄断感、消费龙头偏好 |
| 冯柳 | 赔率优先：下跌空间、预期差、逆向左侧 |
| 邓晓峰 | 产能周期、供需错配、资本开支节奏 |
| 邱国鹭 | 商业模式、行业格局、安全边际 |

## 什么会被否决 / skip

- 段永平：能力圈外商品股（金矿、纯资源）常直接「不懂」。
- 张坤式 GARP：增速不可持续或估值已透支成长。
- 冯柳：赔率差、 crowding 严重时不硬抄。
- 邓晓峰：产能扩张撞上需求下行时偏空。

## 和研报怎么对照

E 组 headline 应出现「懂不懂 / 贵不贵 / 预期差 / 产能」等词，而不是空泛「基本面良好」。若与 A 组同向，说明价值逻辑跨中西一致；若段永平 skip 而格雷厄姆勉强打分，优先信能力圈。

## 一句话边界

中国价投要的是「可理解的复利或赔率」，不是龙虎榜辨识度；主线题材龙不在这派射程里。
