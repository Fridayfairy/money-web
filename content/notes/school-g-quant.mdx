## 这派在回答什么问题

「这只票相对历史与横截面，有没有可度量的统计优势？仓位该多大？」故事是噪声，分位与期望是信号。

## 代表人物

西蒙斯、索普、阿斯内斯、肖氏（`simons` / `thorp` / `asness` / `shaw`）。

## 核心评判维度

| 人物 | 关键规则（插件摘要） |
| --- | --- |
| 西蒙斯 | 多因子/统计套利思维：信号稳定性、换手、过拟合风险 |
| 索普 | 凯利公式、期望值为正才下注；**部分场景可 skip A 股**（数据与可交易性） |
| 阿斯内斯 | 价值+动量等风格因子；拥挤度与价差 |
| 肖氏 | 系统化趋势/量化多策略框架 |

输入偏估值分位、动量、波动、流动性等可向量化字段。

## 什么会被否决 / skip

- 索普：样本不足、摩擦过高、规则无法执行 → skip。
- 单因子「看起来便宜」但拥挤、流动性差：阿斯内斯式会降权。
- 把叙事当 alpha：量化派应降分。

## 和研报怎么对照

G 组分数应能落到「分位 / z-score / 期望」语言。若某张卡片突然写成巴菲特式护城河散文，多半是 agent 串台，可信度下降。

## 一句话边界

量化派买的是**可重复的优势**，不是一次讲对的故事；A 股微观结构若不支持模型，skip 比硬打分更诚实。
