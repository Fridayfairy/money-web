## 这派在回答什么问题

「现在宏观与情绪处在哪个阶段？这只股票是顺风还是逆风？赔率是否不对称？」单季 ROE 不是主菜。

## 代表人物

索罗斯、达里奥、霍华德·马克斯、德鲁肯米勒、罗伯逊，以及偏找雷的伯利、查诺斯（共 7 人）。

## 核心评判维度

| 人物 | 关键框架（插件摘要） |
| --- | --- |
| 索罗斯 | 反身性阶段：初期/加速/顶峰/崩溃；顶峰与崩溃偏观望或反向 |
| 达里奥 | 长期债务周期位置、信贷环境、全天候配置里该资产的角色 |
| 马克斯 | 市场温度计 0–100：**温度越低分越高**（逆向）；贪婪区回避 |
| 德鲁肯米勒 | 流动性拐点；投 12–18 个月后的世界；趋势不清就不集中 |
| 罗伯逊 | 行业内相对强弱 |
| 伯利 / 查诺斯 | 泡沫估值、减持、会计与治理雷——偏空或 skip 多头叙事 |

## 什么会被否决 / skip

- 把「审计干净」当成查诺斯式买入理由——那是规则幻觉；他找的是做空逻辑。
- 加息/实际利率上行、无息资产机会成本上升时，黄金股等利率空头不应被温度计打成 100 分多头。
- 宏观趋势不明时，德鲁肯米勒倾向轻仓或不做。

## 和研报怎么对照

看 C 组是否引用利率、金价、情绪分位，而不是只抄财务比率。若骨架分给马克斯满分「情绪低」，要核对当下到底是恐惧还是「金价仍在历史高位的回撤」。

## 一句话边界

宏观派交易的是**阶段与赔率**，不是公司故事本身；故事再好，顶峰反身性里也可以是卖点。
