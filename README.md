# 个人投资助手

Cursor 云端或本地打开这个仓库，按 30 万做到 50 万的 A 股短线风格做判断，结论记在 Notion。

GitHub 只负责同步这份知识和技能。推送不会再构建网站。Vercel 项目如果还连着这个仓库，到 Vercel 控制台把连接断开，否则每次推送仍会空跑一次部署。

## 目录

- `.cursor/rules/` 判断风格和证据标注。每次对话都生效。
- `.cursor/skills/a-share-open/` 早盘和要不要做。
- `.cursor/skills/a-share-event/` 一条消息、政策、题材事件的六问卡。
- `.cursor/skills/a-share-dragon-tiger/` 龙虎榜怎么读。上游是 FinClaw，Apache 2.0，文件未改。
- `knowledge/` 仓位手册、接口和习惯。
- `AGENTS.md` 助手进门先看的读取顺序。

每日流水、随笔、流派都不在这里。看盘日志和随笔都在 Notion。
