# 知识地图

早盘操作不从这里起读。起读顺序在 `AGENTS.md`。这里是仓库里每份东西干什么。

随笔和流派不在仓库里。它们在 Notion 随笔，入口是「流派」。早盘不读那九篇。30 万到 50 万靠亏损的形状，这条主逻辑也在随笔里，早盘读技能，不读它。

## 手册

在 `knowledge/playbooks/`。用之前先过早盘技能。预警是不开新仓时，手册不能把仓位加回去。

- `signal-grade-sizing.mdx` 清晰度打分和仓位上限。打板接力按一字跌停算亏损，上限约 40%。
- `flat-before-position.mdx` 先写无仓结论，再写动作。
- `position-and-fees.mdx` 手续费和可回测规则。
- `stock-pool-ai-robot.mdx` AI / 机器人票池的筛选口径。
- `panel-overview.mdx` 旧评审团分数怎么读。本地没有报告可打开。
- `gold-miners-stampede.mdx` 金价和矿股的一次读法。
- `yanfu-quant.mdx` 衍复和小市值容量。结论页在 Notion 随笔「衍复：小市值到顶」。
