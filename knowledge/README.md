## 背景，不替代早盘技能

流派笔记在 `knowledge/schools/`。除了游资派，其余八份是评审视角，不拿来改预警档。

- `school-a-classic-value.mdx` 经典价值
- `school-b-growth.mdx` 成长
- `school-c-macro-hedge.mdx` 宏观对冲
- `school-d-technical.mdx` 技术趋势
- `school-e-china-value.mdx` 中国价投
- `school-g-quant.mdx` 量化
- `school-h-tech-leaders.mdx` 科技领袖
- `school-i-serenity.mdx` 卡位打分

手册在 `knowledge/playbooks/`。

- `signal-grade-sizing.mdx` 清晰度打分和仓位上限。里面的账户约 30 万是 2026-09-20 写下的，不是实时净值。
- `flat-before-position.mdx` 先写无仓结论，再写动作。
- `position-and-fees.mdx` 手续费和可回测规则。
- `stock-pool-ai-robot.mdx` AI / 机器人票池的筛选口径。
- `panel-overview.mdx` 旧评审团分数怎么读。
- `gold-miners-stampede.mdx` 金价和矿股的一次读法。
- `yanfu-quant.mdx` 衍复和小市值容量。

`knowledge/essays/` 是随笔，不是交易规则。

`knowledge/reports/` 只留 2026-09 三份评审的结论行和 `meta.json`。原先的 HTML 和头像随网站删了。
